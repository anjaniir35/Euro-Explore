## Required Features

The following **required** functionality is completed:


- [x] **The web app contains a page with a form to add a new city**
  - Users can enter a city's name and other details
  - Users can select values for fields such as country and region
- [x] **The web app includes a summary page displaying all added cities**
  -  The dashboard displays the cities stored in the user's collection
  -  Users can browse the available destinations through city cards
- [x] **Previously added cities can be updated**
  - Each city has an edit option that takes users to an update form for that city
  - Users can view the city's existing information in the form
  - After editing a city's details, the updated information is reflected in the app 
- [x] **Previously added cities can be deleted**
  - Users can delete a city through its edit form
  - After deletion, the city is removed from the dashboard and the database
  - [x] **Each city has its own detail page**
    - Clicking on a city opens a dedicated page with its information
    - The detail page displays additional information about the destination
    - Users can navigate to the edit form directly from the detail page

The following **optional** features are implemented:

- [] Cities can be assigned categories that restrict the available attribute options
- [x] The dashboard displays summary statistics about the saved destinations, including interactive charts
- [ ] The dashboard includes a custom success metric that changes the appearance of the city list

The following **additional** features are implemented:

* [x] Search and filter cities by name and region
  [x] Interactive charts and dashboard statistics
  [x] Wikipedia API integration for city information
  [x] Related city recommendations
  [x] Responsive design for different screen sizes
  [x] Supabase database integration for storing city information
  [x] Add, edit, and delete city functionality
